# 开源贡献成果总结（权威源）

本目录保存已完成或阶段收口任务的正式总结。每份任务总结完成后，通过 `python3 scripts/sync_with_plana.py push-summaries` 同步回 `../PlanA/开源贡献/成果总结/`。

- 新建总结请复制 [`_template.md`](_template.md)，按 `YYYY-MM-DD-<repo>-<id-or-topic>.md` 命名。
- 若 PR 后续状态发生变化（例如从“评审中”变为“已合并”或新增复测数据），先更新本目录对应文件，再重新执行 `push-summaries` 同步回 `PlanA`。
